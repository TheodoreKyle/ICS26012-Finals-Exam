This Java Program is about CPU and Disk Scheduling Algorithms, specifically Multilevel Queue and Round Robin for the CPU,
and Shortest Seek Time First and First Come First Serve for the Disk.  

**Step-by-Step Installation and Running Instructions**
No formal installation wizard is required for either format:

1. Running the JAR File 
- Ensure Java 24 or higher is installed on your machine.
- Download or copy 3ITB - Deadlockers.jar to a standard user folder.
- Double-click 3ITB - Deadlockers.jar or run java -jar "3ITB - Deadlockers.jar" in any terminal to run the application.
- Note: If double-clicking the .jar file displays a "Java Exception has occurred" error or fails to open, your system's default .jar handler may be set to an older Java version.

2. Running the Windows Executable Package
- Download the ZIP file
- Extract All Files: Right-click the .zip file, select Extract All..., choose a destination folder, and click Extract.
- Open the extracted 3ITB - Deadlockers folder and double-click 3ITB - Deadlockers.exe
- Bypass the Windows Defender SmartScreen Warning (First Launch Only): Because this is an executable without a commercial digital signature, Windows Defender SmartScreen may display a blue "Windows protected your PC" pop-up when opening the file for the first time. This is expected behavior for unsigned .exe files downloaded from the internet and is safe to bypass:
    - On the pop-up, click More info (under the warning text).
    - Click the Run anyway button that appears at the bottom of the dialog.
    - The 3ITB - Deadlockers simulator will launch normally.
